# 3-Minute Recruiter Demo

## Goal
Show that Saito is not a static dashboard: it is an API-orchestrated quant research product.

## Script

1. Open `01_Data_Hub` and load via `API router` using `premium-first`.
2. Show provider diagnostics and provenance metadata.
3. Open `13_Research_Studio`:
   - factor/risk panel (beta + VaR/CVaR),
   - strategy panel with walk-forward and overfit gap.
4. Open one advanced lab (`14_Risk_Portfolio_Lab` or `15_Derivatives_Vol_Lab`) to show depth.

## Talking Points

- Multi-provider fallback and reliability behavior.
- Research-grade diagnostics with transparent assumptions.
- Product-level UX with explainable insights.
